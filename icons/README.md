# Icons

Status icons for PASS and FAIL badges come from **Font Awesome Free 7.3.1** (solid): `circle-check.svg`, `circle-xmark.svg`.

- **License:** icons CC BY 4.0, fonts SIL OFL 1.1, code MIT (`LICENSE.txt`, the upstream file). CC BY requires attribution, so every HTML and PDF report prints "Status icons: Font Awesome Free by Fonticons, Inc. (CC BY 4.0)" in its Evidence footer. The attribution comment inside each SVG is stripped when the icon is inlined, and the footer replaces it.
- **Why SVG and not the icon font:** Red Hat Text has no check or cross glyph, and a font would add a dependency to every output engine.
- **Source:** [FortAwesome/Font-Awesome](https://github.com/FortAwesome/Font-Awesome), tag 7.3.1, `svgs/solid/`.
